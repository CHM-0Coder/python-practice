# Python Practice

This repository contains my Python practice exercises focused on string manipulation, numeric data types, arithmetic operations, and basic programming fundamentals.

## Topics Covered

### 1. Python String Methods
- Finding characters using `find()`
- Checking substrings using `in`
- Cleaning strings using `strip()`
- Changing letter case using `upper()`, `lower()`, and `title()`
- Extracting usernames using string slicing
- Replacing characters using `replace()`
- Splitting and joining strings
- Checking prefixes and suffixes using `startswith()` and `endswith()`
- Counting characters using `count()`

### 2. Integers, Floats, and Arithmetic Operations
- Understanding integers (`int`) and floating-point numbers (`float`)
- Performing addition, subtraction, multiplication, and division
- Using modulo (`%`), floor division (`//`), and exponentiation (`**`)
- Working with positive and negative numbers
- Converting values using `int()` and `float()`
- Using built-in functions such as `round()`, `abs()`, and `pow()`
- Understanding floating-point representation and rounding errors

### 3. Augmented Assignment Operators
- Updating variables using `+=`, `-=`, `*=`, and `/=`
- Using `//=`, `%=`, and `**=`
- Understanding how augmented assignments work
- Calculating and updating running totals

## Practice Projects

- **String Methods Practice (`string_methods_practice.py`):** Exercises focused on Python string manipulation and basic text processing.
- **Bill Calculator (`bill_calculator.py`):** A simple bill calculator that calculates the total bill, adds a 25% tip, and divides the final amount among four people.

This repository is part of my journey to learn Python and strengthen my programming fundamentals through consistent practice and hands-on exercises.
