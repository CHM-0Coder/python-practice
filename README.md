# Python Practice

My Python practice exercises covering strings, numbers, operators, conditionals, and functions.

## Topics Covered

### 1. String Methods
- Finding and counting characters with `find()` and `count()`
- Checking substrings with `in`, `startswith()` and `endswith()`
- Cleaning and changing case with `strip()`, `upper()`, `lower()` and `title()`
- Slicing, replacing, splitting and joining strings

### 2. Numbers and Arithmetic
- Integers (`int`) and floats (`float`)
- Basic operations, plus `%`, `//` and `**`
- Type conversion with `int()` and `float()`
- Built-in functions: `round()`, `abs()` and `pow()`
- Floating-point rounding errors

### 3. Augmented Assignment Operators
- `+=`, `-=`, `*=`, `/=`, `//=`, `%=` and `**=`

### 4. Conditional Statements
- Comparison operators: `==`, `!=`, `>`, `<`, `>=`, `<=`
- `if`, `elif` and `else` statements
- Combining conditions with `and` and `or`
- Boolean values and nested conditionals

### 5. Functions and Scope
- Defining and calling functions with `def`
- Parameters, arguments and the `return` keyword
- Local vs. global scope
